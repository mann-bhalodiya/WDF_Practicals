PRACTICAL 11 — STUDENT MANAGEMENT CRUD
Files: schema.sql, db.php, index.php
1. Start Apache and MySQL in XAMPP.
2. Import schema.sql in http://localhost/phpmyadmin/
3. Copy this folder to C:\xampp\htdocs\Practical11
4. Visit http://localhost/Practical11/index.php
Default XAMPP credentials often use root with a blank password. Update db.php if needed.
Features: Create, Read, Update, soft Delete/Restore, search by name/email/course, course filter, pagination, CSV export, validation and status messages.
